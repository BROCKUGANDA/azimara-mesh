# AZIMARA MESH — Go-To-Market

## Positioning
**The governed operating fabric for autonomous AI.** AZIMARA MESH is not another
agent builder or chat wrapper — it is the operational control plane between AI
models, autonomous agents, business systems and the people accountable for them.

Primary line: **Every Agent. One Governed System.**

## ICP
1. **Platform/ML engineering teams** in regulated mid-to-large organisations running
   multi-framework agent fleets (LangGraph, CrewAI, OpenAI SDK, MCP) who need
   governance without rewriting agents.
2. **Operations leaders** who must answer "what are our agents doing and what did it
   cost" with evidence.
3. **Risk & compliance** functions requiring deterministic policy, approvals and
   audit trails independent of model behaviour.

## Wedge
The **approval gate + evidence trail**: agents keep working, but every consequential
action becomes a policy decision with a human checkpoint where it matters. This is
demonstrable in minutes (refund gate demo) and requires zero agent rewrites.

## Motion
1. **Design-partner pilots** (Phase 7): 3–5 teams, seeded workspaces, weekly evidence
   reviews. Success metric: governed executions with zero silent side effects.
2. **Developer-led entry** (Builder tier): Studio + Evaluation Lab + Developer
   Portal; deterministic eval suites as the hook.
3. **Enterprise expansion** (Team → Enterprise): fleets, SSO/SCIM, private runtime
   pools, audit exports.

## Narrative rules (enforced company-wide)
- Never manufacture adoption, uptime, execution counts or evaluation scores.
- Never claim production deployment without verifying the deployed environment.
- Demo data is labelled as demo data — in product, not only in docs.

## Launch sequence
1. Technical briefs: policy engine + execution plane deep dives (this docs set).
2. Golden-path demo video: refund approval gate end-to-end (implemented here).
3. Pilot program with the Community/Builder tiers; pricing per PRICING.md.
4. Marketplace foundations only after the trust model is verified (directive §49).
